PrivAgent demo site

Mock pages for developing, demoing and scoring the redaction pipeline

What this is

Three pages that between them cover the cases the privacy filter has to handle. Every sensitive element carries a data-pii="TYPE" attribute, which is the ground truth the eval harness scores against — and the same annotation the synthetic data engine turns into YOLO labels.

  • KYC & scholarship application Form fields: password, Aadhaar, PAN, card, OTP, IFSC, UPI, address, photo and a scanned ID card. Mixed labelling conventions — some fields declare autocomplete, some only have a snake_case name.
  • Profile page No form fields at all: every value is page text, including one split across elements and one that wraps across lines. Tests the text layer and its pixel rects.
  • Bank details PII-dense enough that redaction should cover a large share of the screen and push the pipeline down to structure-only disclosure. Includes decoy numbers that must not be redacted.

Serving it

Content scripts run on file:// only if you grant file access, so serve it over HTTP instead: 

python3 -m http.server 5173 --directory demo-site

Then open http://localhost:5173/kyc.html and press Analyze page.
